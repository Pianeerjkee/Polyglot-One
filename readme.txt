КОНФИДЕНЦИАЛЬНОСТЬ
Polyglot One уважает вашу конфиденциальность и стремится защищать ваши данные. 

1. **Сбор данных:**  
   - Программа обрабатывает только текст, который вы сами выделяете на экране для перевода. 
   - Скриншоты и текстовые данные **не сохраняются на вашем устройстве** и **не передаются третьим лицам**.

2. **Использование данных:**  
   - Выделенный текст временно отправляется в сервис перевода Google Translate для получения перевода.  
   - Polyglot One не использует данные для рекламы, аналитики или любых других целей.  

3. **Безопасность:**  
   - Программа не собирает никакую личную информацию пользователя.  
   - Данные обрабатываются локально на устройстве и в момент работы с переводом.  

4. **Согласие пользователя:**  
   - Используя Polyglot One, вы соглашаетесь на обработку **только выделенного текста** для перевода.  
   - Никакая дополнительная информация о вашем устройстве или действиях не собирается.
